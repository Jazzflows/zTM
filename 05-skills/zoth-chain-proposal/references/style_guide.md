# Zoth Proposal Style Guide

Saksham reviews every proposal. These are the patterns that have worked.

## Voice

**VC analyst, claim-first.** Lead with the assertion or number. Justify in the next clause if needed.

| Bad | Good |
|-----|------|
| In order to deliver value to our partners, Zoth has built a comprehensive stablecoin infrastructure platform that... | Zoth runs $25M+ monthly TPV across 160+ countries at 99.1% success rate. |
| We are excited to partner with Avalanche on this transformative journey... | $25M anchor, $2.5M grant, 90 days to $100M TVL. |
| Our solution leverages cutting-edge blockchain technology to enable... | zVault: up to 12% APY, CIMA/BVI regulated, MPC custody. |

## Section openings

Every section opens with a one or two sentence claim. No "in this section" or "we will now discuss".

**Bad:** "In this section, we will outline our approach to building the partnership and explain how Zoth will deploy on Avalanche over time."

**Good:** "Zoth's deployment on Avalanche follows a deliberate two-phase build."

## Linking sentences

Between sections, use one linking sentence maximum, or none. Tables and headers do the work.

## Tables

Use a table when:
- Comparing 3+ items on the same dimensions
- Mapping inputs to outcomes (Gap × Opportunity, Strength × What X Gets)
- Listing milestones, KPIs, or partnership requirements
- Anything that would otherwise be a prose paragraph followed by a bullet list

Don't use a table when:
- 2 items only (use prose)
- Single concept that just needs a number (use callout)

Table header rows are always Zoth orange (`#F58220`) with white text. Body rows alternate plain and `#FAFAFA`.

## Bullets

- Verb-led where possible ("Deploys", "Settles", "Earns")
- Parallel grammar across siblings
- One concept per bullet
- 5 to 15 words is the sweet spot
- Never end on a vague bullet ("and more", "etc")

## Forbidden phrases and constructions

| Don't write | Why |
|-------------|-----|
| Em dash (—) or en dash (–) | Saksham's hard rule. Use comma, period, parens, or restructure. |
| "Leverage" | Corporate filler. Say "use" or be specific. |
| "Synergy" | Empty word. Show the actual interaction. |
| "Best-in-class" | Subjective. Show the metric. |
| "Robust" | Subjective. Quantify. |
| "Game-changing" / "transformative" / "disruptive" | Pitch deck cliche. |
| "We are excited to..." | Cut and rewrite as a claim. |
| "As you can see from the table above..." | Restating a table is filler. Cut. |
| "It's important to note that..." | Filler. State the thing directly. |
| "In conclusion" / "in summary" | The conclusion section already says it's the conclusion. |

## Numerical asks

Always bold or color-accent the headline ask. Patterns that work:

```
The Proposition: $25M anchor liquidity into zVault Liquid Yield Assets, $2.5M
milestone-gated grant, chain incentive co-funding across three liquidity seasons.

The ask: $25M anchor + $2.5M grant + chain incentive co-funding + co-marketing.

The return: 50,000 to 200,000 active users, $100M+ sticky TVL.
```

Format the labels ("The Proposition:", "The ask:", "The return:") in the orange accent color, body in default text.

## Numbers and units

- Use $25M not "$25 million" or "twenty-five million"
- Use 11% not "11 percent"
- Use 1.8M+ wallets not "more than 1.8 million wallets"
- Use "up to 12% APY" not "as high as 12% per annum"
- Currency goes with the number: $5M, Rs 25B, 160+ countries
- Ranges: "50K to 200K" not "50K-200K" (the dash rule applies even here)

## Capital loop pattern

The capital loop sentence is the most-quoted line in every proposal. Pattern:

> User deposits USDC, earns up to 12% in zVault, 1-tap allocates to zStocks (NVDA, MSFT, GOOGL, META), dividends auto-compound to vault, settles cross-border via zPayments, spends via Zocta Card. Balance stays on [Chain]. Every day capital stays, switching cost compounds.

Keep this rhythm. Verb, product, outcome, comma. End with the lock-in claim.

## Conclusion pattern

Three short paragraphs maximum:

1. Positioning sentence: "[Chain] brings X. Zoth brings Y. Together, [outcome]."
2. The ask, accented.
3. The return, accented.

Then a single centered line: "www.zoth.io  |  Zoth, The Stablecoin Neobank"

## Headers and page weight

| Element | Style |
|---------|-------|
| Title | 48pt, bold, black text, orange underline rule |
| H1 | 30pt, bold, Zoth orange |
| H2 | 24pt, bold, Zoth orange |
| Body | 20pt regular |
| Table header | 18pt bold, white text on orange |
| Table body | 18pt regular, dark grey |
| Footer | 16pt grey, page number centered |

Margins: 0.75 inch all sides for 8-page concise. 1 inch for 13-page expanded.

## Things Saksham will personally fix and re-flag

- Any "approximately" instead of "~"
- Any phrase like "as outlined above" referencing internal navigation
- Any bullet starting with "Helps to..." or "Enables..." (verb-led without the helper)
- Spelling "USDze" or "USDze" or any variant; if used, it's "USDZe" exactly. (Note: per recent direction, USDZe should be removed entirely, replaced with "zVault Liquid Yield Assets".)
- "BUIDL/BENJI/ACRED" name-drops unless explicitly approved
- Markets list using Oxford comma where the rest of the doc doesn't (be consistent)
- Tagline that doesn't mention the chain by name
