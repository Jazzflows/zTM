# Example Documents

This folder holds real Zoth documents to read for **form, not facts**: structure, section ordering, phrasing, table design, and register. Use them as worked examples of what good Zoth output looks like.

## How to use these

- **Read for structure and voice.** When asked to produce a similar artifact, mirror the section flow, the table-heavy layout, the claim-first phrasing, and the analyst register these demonstrate.
- **Do not treat their numbers as current.** Examples can contain figures that have since changed (Strategy AUM, TPV, APY, partner status, fees). Always verify any specific number against the product overviews in `references/`, never against an example document. If an example and an overview disagree, the overview wins.
- **Do not copy stale or off-style passages.** If an example uses a banned term (private credit, USD, bare AUM, a dash) or an old number, follow `references/house_style.md` and the overviews instead. The examples are illustrative, not authoritative.
