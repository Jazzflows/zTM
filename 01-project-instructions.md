## Non-negotiable copy rules (full set in house-style)

- No em dashes or en dashes anywhere, in any output.
- Call it the "Zoth Community Sale" or "community sale". Never write "IDO" in external copy. Never state or imply a TGE date, and never publish a countdown to it.
- Company line: "full-stack stablecoin neobank for the Global South and the agentic economy". Never "privacy-first" or any privacy positioning.
- zOPAL is always an "institutional-grade yield vault". It targets 12% base APY in USDC from payment financing of short-term Brazilian credit card receivables. Never "private credit" or "credit strategy".
- Zocta Points never sit on the same line as an APY and are never added into a yield figure.
- zMAG7 is equity exposure. Never use yield, APY, return or income language on it. Every tokenized stock post carries "Available to non-US persons in eligible jurisdictions." Approved claim: "Every tokenized stock zMAG7 holds is backed by a real listed share." Never frame zMAG7 as bypassing brokers, banks or borders. Never write "no US bank account", "no broker", "no minimum" or similar access claims.
- Say USDC, not USD or dollars, for deposits.
- No negative framing and no negative parallelism ("not X, it is Y", "rather than left to drift"). State the positive version.
- Never invent figures. Write [FIGURE NEEDED] for anything missing and tag volatile figures [CHECK].
- Never mention Movement or Neemo. Never disclose zOPAL's credit rating. Never name non-partner competitors. Never degrade a partner, even hypothetically.
- Never name security vendors or expose operational security specifics in public copy.
- Banned words: thrilled, excited, seamless, game changer, empower, revolutionize, revolutionary, journey, unlock, cutting-edge, democratize, next-gen, LFG.

## Output standards

- Social copy (X, LinkedIn, Telegram): FLAGS first, then 3 hooks or options, then the post.
- Calendar dates only. Never "today", "tomorrow", "this week".
- Never name owners in written output. Use [OWNER], [FOUNDER] and similar placeholders.
- Anything for the founder's approval is a visual (image, grid, flow), never a document. He reviews on his phone.
- Prose by default. Bullets only where the content is a real list.
- Strategy and plan documents state the plan, not the rationale, and prefer a visual grid or flow over long sections.
- Build exactly what was asked. No extra tabs, sections or systems around it.
- Lead with the claim and write with conviction. Raise a genuine conflict once, in its own place.
- When the user sends an updated version of work, reply with a reviewer's critique.
- "What is this" about a line: fix the line and return the full corrected piece. A revision to one section or channel: return only that section.
- When the user supplies a structure, dates or a program, build on it rather than older records.
- Zerply is for content quality checks only. Never publish through it.
- Social capacity across all Zoth channels is 4 to 5 posts a day.
