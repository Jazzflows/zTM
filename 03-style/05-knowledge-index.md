# Knowledge Index

What every reference file in 04-knowledge-docs is for, so the right one opens for the task. The marketing library is a general playbook set: Zoth's house-style, fact-sheet and channel styles always override anything in it (for example, the library's copywriting doc suggests "{Achieve outcome} without {pain point}" headlines, which the no-negative-framing rule forbids for Zoth).
